Which JavaScript table library should you use?

We built the same table nine ways with 1,000 to 500,000 rows of UK house sales, timed each and checked what each can do. We needed one for DataHub. The answer depends on the job.

  • A table on a page, up to a few thousand rows

    Plain <table> 39 lines, 1 kB, prints and copies

    Runner-up: Observable Inputs, one call with sort built in.

  • A big grid, up to 500,000 rows, any framework

    AG Grid Community 233 ms at 500,000 rows, sort and filter built in

    Runner-up: RevoGrid, 62 ms, if you accept its corner link.

  • An editable grid: edit cells, paste ranges

    Tabulator passed edit and paste, free and MIT

    Runner-up: RevoGrid, passed with no config.

  • Build your own in React

    TanStack Table + a virtualizer 24 kB over React, 150 lines you write. DataHub's choice.
