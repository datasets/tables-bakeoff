The [front page](https://tables.datahub.io/) now opens with what we did, in two sentences, beside a real grid, and then a table: the job you have, what to use, the runner-up, and why in one line. A table on a page gets a plain `<table>`. A big grid gets AG Grid Community. An editable grid gets Tabulator. If you want to build your own in React, TanStack Table, which is what DataHub uses. Under it, every library live at 1,000 rows, a short version of the numbers, what each can do, and copy-and-paste starter code for each pick.

![The front page: what we did, a real grid, and the table of jobs and picks](/changelog/2026-11-21-picks-by-job.png)

- **A feature table.** Thirteen features across all nine, from sort to paste to keyboard, each marked built in, needs config, paid tier or you write it, read from the docs and from our own tests.
- **Starter code.** The install line and the shortest code that renders a sortable table, for every library, each one loaded and checked.
- **[Compare](https://tables.datahub.io/compare.html)** holds the full numbers: 50,000 and 500,000 rows, scroll, text selection, keyboard sort, the edit test, the scorecard and the method.
- **[Why](https://tables.datahub.io/why.html)** says why we did this, how we measured, what DataHub chose and what we did not test.
