Which JavaScript table library should you use?

We built the same table nine times: eight libraries and a plain <table>. We timed them from 1,000 to 500,000 rows, compared what each can do, and picked one for each job.

What to use

It depends what the table is for. Three jobs, a pick and a runner-up for each.

The jobUseRunner-upWhy
A table on a pageA report, an article, docs. Up to a few thousand rows. Plain <table>no library Observable Inputs, one call, sort on click. For a search box, DataTables. 1 kB, 39 lines, 1,000 rows in about 55 ms. Prints, copies, Ctrl-F finds every row.
A big gridTens of thousands to 500,000 rows. Sort and filter built in. Any framework. AG Grid CommunityMIT, vanilla RevoGrid, 62 ms at 500,000 rows, with a corner link. 233 ms for 500,000 rows at 60 fps, sort and filter built in, 40 lines, 333 kB. See it do more
An editable gridEdit cells, paste ranges. Spreadsheet-like. TabulatorMIT, vanilla RevoGrid, passed the edit test with no config. Edit and paste both pass, free, no framework, 112 kB. Give its parent a height.
Build your ownReact, your markup and CSS. TanStack Table + a virtualizer 24 kB over React, 150 lines you write. What DataHub uses.
